# Example Extension

- Copy `example-extension.rext` to your Reviactyl root directory.
- Run the command `php artisan extension:install example-extension` to install the extension.
- Run the command `php artisan extension:enable example-extension` to enable the extension.

## Development

- Run Command `php artisan d:extension:dev example-extension`
- Then run `php artisan d:extension:watch example-extension` for live build.
- Run `php artisan d:extension:compile example-extension` to build & compile the extension for production.
